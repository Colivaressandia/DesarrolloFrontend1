Memory Card Games - Tienda de Videojuegos
Proyecto formativo de desarrollo web correspondiente a la actividad "Optimizando la página web con CSS" (Semana 2).

El objetivo principal es estructurar y optimizar visualmente una tienda online de videojuegos utilizando HTML5 semántico y una hoja de estilos externa en CSS3, aplicando buenas prácticas de diseño responsivo y modelos de maquetación modernos.

🛠️ Tecnologías y Conceptos Aplicados
HTML5 Semántico: Uso adecuado de etiquetas estructurales (<header>, <nav>, <main>, <section>, <footer>) e identificadores (id) para navegación interna sin enlaces rotos.

Variables CSS (:root): Definición centralizada de paleta de colores corporativa (tema gamer oscuro y acentos cian/verde) y tipografías para facilitar el mantenimiento.

Modelo de Cajas (Box Model): Implementación de box-sizing: border-box, control preciso de padding, margin, border y bordes redondeados (border-radius).

Navegación Fija e Interactiva: Barra de navegación con position: sticky y soporte para desplazamiento suave (scroll-behavior: smooth).

Selectores Avanzados:

Pseudo-clase :hover para transiciones e interactividad en botones y tarjetas de productos.

Pseudo-clase :nth-child() para destacar elementos clave del catálogo.

Selectores de atributo (a[target="_blank"]) para estilizar enlaces externos.

Diseño Responsivo (Media Queries): Adaptación del diseño y menú de navegación para dispositivos móviles y tablets mediante @media (max-width: 768px).
