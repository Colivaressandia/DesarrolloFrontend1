# Memory Card Games - Tienda de Videojuegos

Proyecto formativo correspondiente a la **Semana 1** de la asignatura **Desarrollo Frontend I (PFY2201)**.

El objetivo principal es construir la maqueta base y la estructura semántica en **HTML5** para una tienda online de videojuegos y consolas, aplicando estándares de accesibilidad, jerarquía de contenido y buenas prácticas de desarrollo web.

---

## 📌 Contenido y Estructura del Sitio

El documento HTML está organizado mediante las siguientes etiquetas semánticas y elementos:

* **`<header>`**: Contiene el título principal de la tienda (`<h1>`), un párrafo descriptivo (`<p>`) y el menú de navegación (`<nav>`) con enlaces internos (`<a>`).
* **`<section id="productos">`**: Sección con subtítulo (`<h2>`) y una lista no ordenada (`<ul>`) con los productos destacados. Cada producto incluye:
  * Título del artículo (`<h3>`)
  * Imagen referencial (`<img>`) con dimensiones explícitas, carga diferida (`loading="lazy"`) y texto alternativo descriptivo (`alt`).
  * Párrafo descriptivo (`<p>`)
  * Precio destacado mediante formato de énfasis (`<strong>`).
* **Enlace a Comunidad**: Enlace externo seguro configurado con `target="_blank"` y `rel="noopener noreferrer"`.
* **`<footer id="contacto">`**: Pie de página con información de contacto (dirección, teléfono, correo) y derechos reservados.
