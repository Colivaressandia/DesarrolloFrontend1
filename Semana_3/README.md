# Memory Card Games - Actividad Sumativa Semana 3

Proyecto correspondiente a la evaluación sumativa **"Optimizando un Sitio Web con HTML, CSS y Diseño Responsivo"** de la asignatura **Desarrollo Frontend I (PFY2201)**.

El objetivo principal es estructurar y optimizar visualmente un e-commerce de videojuegos aplicando HTML5 semántico, CSS Grid, Flexbox, variables CSS y diseño responsivo adaptado a múltiples resoluciones.

## 🛠️ Características y Conceptos Técnicos Implementados

* **HTML5 Semántico:** Estructura modular y accesible utilizando `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` y `<footer>`, con identificadores (`id`) para navegación interna fluida.
* **Layout con CSS Grid:** Organización del catálogo de productos y secciones principales en grillas adaptables bidimensionales.
* **Maquetación con Flexbox:** Alineación y distribución de elementos horizontales en la barra de navegación (`sticky`) y en el pie de página.
* **Modelo de Cajas (Box Model):** Implementación de `box-sizing: border-box`, control riguroso de `padding`, `margin`, `border` y `border-radius` para una delimitación clara.
* **Variables CSS (`:root`):** Paleta de colores gamer optimizada en modo oscuro con acentos cian y verde neón, facilitando escalabilidad y mantenimiento.
* **Selectores Avanzados (Sin `!important`):**
  * Pseudo-clase `:hover` para transiciones e interactividad en botones y tarjetas de productos.
  * Pseudo-clase `:nth-child(2)` para destacar visualmente el producto más popular.
  * Selectores de atributo (`a[target="_blank"]`) para enlaces externos.
  * Estados `:focus-visible` para accesibilidad en navegación por teclado.
* **Diseño Responsivo Multidispositivo (Media Queries):**
  * **Escritorio (> 992px):** Layout a 3 columnas.
  * **Tablets (≤ 992px):** Reorganización a 2 columnas.
  * **Móviles Estándar (≤ 768px):** Menú de navegación apilado verticalmente y distribución a 1 columna.
  * **Móviles Compactos (≤ 480px):** Ajuste fino de tamaños de fuente, rellenos y espaciados internos.
